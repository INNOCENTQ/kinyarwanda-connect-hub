# Presentation slides

This folder contains a six-slide illustrated overview of **Umuhinzi AI**, the Rwanda-focused digital assistant for crop farmers and livestock keepers.

## View the presentation

Serve the repository with the project's usual local dev server (`npm run dev`) and open `/slides/` in your browser. The presentation viewer is `index.html`.

Navigate with the on-screen buttons, the left/right arrow keys, Space, Page Up/Page Down, Home/End, or swipe on a touch screen. Use **Fullscreen** for presenting.

## Slides

1. **The mission** — A healthier harvest, a stronger herd
2. **Crops & AI guidance** — Better decisions for every growing season
3. **Livestock & veterinary care** — Healthier animals, stronger livelihoods
4. **Local weather** — Know the weather. Plan with confidence.
5. **Market & connections** — Connect local harvests to opportunity
6. **Made for people & place** — One trusted assistant, built around you
