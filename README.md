# Ubuhinzi & Ubworozi AI

Ubuhinzi & Ubworozi AI is a Rwanda-focused digital assistant for crop farmers and livestock keepers. It brings practical agriculture guidance, livestock support, local weather information, AI-assisted diagnosis, veterinary consultation, and a farmer marketplace together in Kinyarwanda.

## Technology

- React, TypeScript, and Vite
- Tailwind CSS and shadcn/ui
- Supabase authentication, database, and Edge Functions

## Develop locally

```sh
npm install
npm run dev
```

Run the test suite with `npm test` and create a production build with `npm run build`.

The app supports phone-based Rwanda account login and email login. Supabase environment settings are required for authentication and backend features.
